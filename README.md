# Student-Grades-Dashboard
Java desktop application for manging student grades with login, grade entry, and calculation of totals,averages, and pass/fail statistics
# features
login page
Add and manage student grades
calculation of each student's total and average
Statistics showing the number of students who passed
Clean dashboard layout across five pages
# Technologies
JvaFX
# How to run
1-Clone the repository
2- Open the project in your IDE(Netbanes/Intellij/Eclipse)
